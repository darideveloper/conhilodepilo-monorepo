## ADDED Requirements

### Requirement: Cross-Browser Calendar Layout
The booking calendar MUST maintain a consistent and functional grid layout across all supported browsers, specifically Safari on macOS.

#### Scenario: Rendering in Safari on macOS
- **WHEN** the user views the booking calendar in Safari on macOS
- **THEN** the month container MUST be rendered as a grid with proper cell alignment
- **AND** the layout MUST NOT collapse or overflow.
